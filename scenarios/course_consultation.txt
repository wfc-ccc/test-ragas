# 码上学院智能课程咨询与推荐知识库

本知识库用于智能助手进行课程咨询与个性化推荐，基于学员背景、学习目标、基础水平给出建议。

---

## 一、按学习目标推荐路径

### 目标: 转行成为后端工程师
推荐路径: Python 编程入门课（PY-101）→ 算法与数据结构精讲（ALG-180）→ Java 工程师进阶课（JAVA-201）
说明: 零基础学员先用 Python 建立编程思维，再补齐算法基础，最后通过 Java 进阶课掌握企业级后端开发与微服务架构，学完可胜任初中级后端岗位。
预计周期: 6-9 个月。

### 目标: 转行成为前端工程师
推荐路径: Web 前端开发实战（WEB-150）→ 算法与数据结构精讲（ALG-180）
说明: 前端入门门槛相对友好，先通过 WEB-150 掌握 HTML/CSS/JS 与主流框架，再补算法应对面试，学完可胜任前端开发岗位。
预计周期: 4-6 个月。

### 目标: 从事人工智能方向
推荐路径: Python 编程入门课（PY-101）→ 算法与数据结构精讲（ALG-180）→ 人工智能与机器学习（AI-301）
说明: AI 方向对数学与 Python 要求较高，需先打牢 Python 与算法基础，再进入 AI-301 系统学习机器学习与深度学习，最终能独立完成 LLM 应用开发。
预计周期: 9-12 个月。

### 目标: 云原生与高并发后端
推荐路径: Java 工程师进阶课（JAVA-201）→ Go 语言后端开发（GO-220）
说明: 已有后端基础的学员推荐 Java 进阶夯实工程能力，再用 Go 学习云原生与高并发架构，适合向往大厂基础架构方向的学员。
预计周期: 5-7 个月。

---

## 二、按基础水平推荐

### 零基础学员
- 起步课程: Python 编程入门课（PY-101），语法简单、生态丰富，最适合入门
- 不建议直接学: AI-301（数学与 Python 要求高）、GO-220（需后端经验）
- 学习建议: 每天保持 1-2 小时练习，跟随录播 + 直播答疑节奏，先完成 PY-101 再选择方向

### 有基础语法、想进阶
- 推荐根据方向选择: JAVA-201（后端）、WEB-150（前端）、ALG-180（面试）
- 若基础不牢建议先刷 ALG-180 巩固语言与算法

### 有工作经验、想转方向
- 转 AI: 直接 AI-301（需评估数学基础）
- 转云原生: 直接 GO-220
- 转后端: JAVA-201

## 三、课程咨询高频问题

### 哪门课最适合零基础？
Python 编程入门课（PY-101）。Python 语法简洁、上手快、应用广，是公认的零基础首选。课程价格 199 元，40 课时，含直播答疑。

### 想找工作哪门课性价比最高？
Web 前端开发实战（WEB-150）。599 元、60 课时，覆盖 React 与 Vue3 双框架，含两个实战项目，4-6 个月可达到求职水平。

### AI 课程需要什么基础？
AI-301 要求熟练掌握 Python，并了解线性代数与概率统计。零基础学员建议先完成 PY-101 与 ALG-180。

### 课程有试听吗？
所有课程均提供 7 天试学，试学期内可全额退款。可在课程详情页点击「试听」免费观看前 3 节。

### 哪门课有就业推荐？
Java 工程师进阶课（JAVA-201）完成毕业项目并通过答辩后，可推荐就业，合作企业包括多家互联网公司。

---

## 四、推荐逻辑说明

智能推荐会综合以下因素:
1. 学员当前基础（零基础 / 有语法基础 / 有工作经验）
2. 学习目标（求职 / 转行 / 兴趣 / 进阶）
3. 可投入时间（每天 1 小时 / 2-3 小时 / 全职）
4. 预算偏好

推荐时遵循「先基础后进阶、循序渐进」原则，不向零基础学员推荐高级课程，确保学习路径合理可行。
